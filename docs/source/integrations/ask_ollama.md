# 1. Ask Ollama
This extension is similar to [**AI Rephrase**](#source-integrations-ai_rephrase_1._AI_Rephrase), but this time you could ask Ollama AI model to explain, expand or extract main points from selected text. You can select any available Ollama model and pick any answer from it, add it to the text, replace selected text or hide the window:
