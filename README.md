# Doc Editor

This is a Markdown web editor called 'Doc Editor' that uses the [MyST Markdown] under the hood.
MyST is a Markdown on steroids: it provides more advanced tools to make your technical documentation look more anvanced. It's ready for the Wold, PDF, Markdown, LaTeX or Sphinx export. Markdown has very limited tools for that, that's why MyST shines here! Take a look at MyST guide here - https://mystmd.org/guide/quickstart-myst-markdown
'Doc editor' is undestructive editor, it may start to work from the default 'docs' folder. You can see it from 'Quick start' section. It also may use custo 'docs' path and you can edit, create and edit .md files here right from web interface in your browser. After that you can continue from your favourite MD Editor. You can work here, but you'll not see the whole power of MyST in case your editor doesn't have MyST extension. And then you can switch back to 'Doc editor'. 
It has Git integration: you can diff compare branches/commits, create your own branches/commits, pull and commit your own changes.
It uses Excalidraw whiteboards right inside the text editor and generate png with excalidraw scene builtin. Hence you can re-edit this images and re-save it.
It also use Ollama integration: you can ask it (with model setup) about selected text in context or ask it to re-phrase selected text.
